## 📱 Descripción

**Sana** es una aplicación móvil Android diseñada para brindar apoyo emocional y herramientas educativas a estudiantes, docentes y directores de instituciones educativas.

### ✨ Características Principales

#### 🎓 Para Alumnos
- 🤖 **Chat IA**: Asistente emocional con inteligencia artificial (Groq API)
- 🫁 **Respiración Guiada**: 7 ejercicios con animación visual
- 📝 **Diario Emocional**: Registro privado de estados de ánimo
- 🎯 **Planes de Estudio**: Recibe planes personalizados
- 🆘 **Líneas de Ayuda**: 45+ contactos en 8 países
- 📬 **Buzón**: Mensajes y guías de profesores

#### 👨‍🏫 Para Docentes
- 📋 **Bitácora Escolar**: Registro de observaciones por alumno
- 🔗 **Compartir**: Colaboración entre docentes
- 📤 **Publicar Guías**: Material con PDFs e imágenes
- 🎯 **Crear Planes**: Públicos, privados o compartidos

#### 👔 Para Directores
- 📢 **Avisos**: Publica anuncios para docentes
- 🔄 **Gestionar Docentes**: Altas, bajas, códigos
- 📊 **Reportes**: Estadísticas mensuales

#### 🧒 Primaria
- 👨‍🏫 Panel docente con grupos de padres
- 👪 Panel de padres con tareas y economía de fichas
- ⭐ Actividades psicológicas guiadas
